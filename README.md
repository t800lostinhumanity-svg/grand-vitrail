# Le Grand Vitrail pour iPhone

Ce dossier fabrique le fichier `GrandVitrail.ipa` sur un Mac en ligne de GitHub, sans Mac à soi.

1. Mets le contenu de ce dossier dans un dépôt GitHub. La fabrication démarre toute seule.
2. Dans l'onglet **Actions**, attends la coche verte, puis ouvre la fabrication.
3. Dans **Artifacts**, télécharge `GrandVitrail-ipa` et décompresse-le.

Le fichier n'est pas encore signé : un outil comme Sideloadly doit le signer avec un compte Apple pour l'installer sur un iPhone.
Pour une nouvelle version du jeu, remplace le contenu du dossier `www`.
